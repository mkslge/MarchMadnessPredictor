# Style Guide
Use descriptive variable names when needed,
For non-getters and setter methods write a command header above
explaining what the pre and post condition of the method is,
and a short descriptive of what the function does.

For tests add a clear explanation of what is being tested. Do not
write any tests that may not be valid if data is added to surrounding infra.
