# Project Overview
This project is a JDK 24 Springboot March Madness Model designed to be able to model any March Madness tournament, and model a game between any two teams.

# Architecture
Models - Stores representation of objects
Generators - Responsible for generating these objects
Controllers - Backend endpoints 


# Build & Run
mvn spring-boot:run

# Test
./mvn test -q

# Code Style
Use descriptive variable names when needed,
For non-getters and setter methods write a command header above 
explaining what the pre and post condition of the method is,
and a short descriptive of what the function does.

# Testing Rules
Tests should be written with a description of what the function does

# PR / Change Rules
You may change files as needed, if it is a major change, only change
with confirmation.
